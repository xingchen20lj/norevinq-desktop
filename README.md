# Aster Code

Aster Code 是一款面向 macOS 和 Windows 的开源桌面智能编程客户端。它以 Codex app-server 作为本地智能体协议层，并计划原生支持 OpenAI、DeepSeek Responses API、Git 工作树、差异审阅、终端、MCP、技能、计划任务和 Codex Security。

项目正在按无人值守工程计划持续开发。当前进度、下一步和阻塞见：
