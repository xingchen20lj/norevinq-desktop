## 必须手工/视觉验证的状态

- 960×640 最小窗口、常见 1440×900 和高 DPI。
- 深色、浅色、跟随系统。
- 无项目、空任务、加载、离线、无权限、协议不兼容、崩溃恢复。
- 长标题、中文/英文混排、超长路径、大量项目和任务。
- 长活动时间线、连续流式更新、上万行终端、超大 diff。
- 面板折叠、键盘导航、焦点可见性和减少动画设置。
