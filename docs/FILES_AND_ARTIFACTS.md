# 文件与产物预览

文件预览器只接受已登记项目 ID 和可选托管 worktree ID。Renderer 从不提交绝对 cwd，也不能直接读取 `file://` URL。

## 支持范围

- 目录按需读取，每层最多 500 项；`.git` 内部目录不展示。
- 文本与代码按 UTF-8 安全展示，单文件最多读取 2 MiB，超出后明确标记截断。
- 无扩展名文件会读取最多 8 KiB 样本区分文本与含 NUL 的二进制内容，不会为类型检测读完整大文件。
- 图片上限 50 MiB，PDF 上限 100 MiB；音频和视频使用流式响应而不经 IPC 复制完整文件。
- 智能体 `fileChange` 活动中的路径可直接打开；绝对活动路径只会在确认位于当前项目/工作树根目录时转为相对路径。
- “系统打开”需要用户确认，并拒绝可执行权限文件及常见脚本/可执行扩展名。

## 路径与协议边界

主进程逐段 `lstat`，拒绝绝对路径、NUL、`..` 和任何符号链接组件；随后用 `realpath` 再确认目标仍位于项目或托管 worktree 根目录。符号链接会显示在文件树中，但不能遍历或预览。

图片、音视频和 PDF 通过 `aster-file://preview/<opaque-token>` 加载：

- token 是随机 UUID，15 分钟过期，最多保留 128 个；URL 不含本地路径。
- 协议只接受 GET/HEAD，支持单段 HTTP byte range、HEAD、206 和 416。
- 响应固定 `no-store`、`nosniff` 和限制性 CSP；Renderer CSP 只对图片、媒体和 frame 开放此自定义安全 scheme。
- token 解析后仍重新检查目标是普通文件；项目切换或应用退出不会把路径写入 Renderer 持久状态。

## 验证证据

- 单元测试覆盖路径逃逸、绝对路径、符号链接、无扩展名文本、二进制识别、2 MiB 截断、图片/PDF上限、token 过期、外部打开限制和 byte range。
- Electron E2E 从真实 app-server 文件变更活动打开 `ASTER_APPROVAL_OK` 文本，并通过自定义协议解码真实 1×1 PNG，断言 `naturalWidth=1`。
- 1320×840 浅色文本与图片截图已检查；文件树、标题、预览区和系统打开按钮无明显溢出。
