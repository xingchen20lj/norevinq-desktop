# 界面与交互

## 命令与快捷键

`⌘K`（macOS）或 `Ctrl+K`（Windows）打开命令面板；`⌘⇧P`/`Ctrl+Shift+P` 同样可用。面板支持文字过滤、上下箭头、Enter 和 Escape，禁用项不能执行。

核心快捷键：

| 操作 | macOS | Windows |
|---|---|---|
| 命令面板 | `⌘K` | `Ctrl+K` |
| 新任务 | `⌘N` | `Ctrl+N` |
| 当前上下文终端 | ``⌘` `` | ``Ctrl+` `` |
| 关闭最上层工作台 | `Esc` | `Esc` |

命令面板只路由到已实现的真实服务：项目、任务、文件、终端、本地浏览器、Git、计划任务、安全、设置和外观。当前映射是经过冲突检查的固定核心集合；用户级完全重映射尚未实现。

## 主题和布局

- 首次启动默认“跟随系统”，监听 `prefers-color-scheme` 实时变化。
- 用户可固定浅色或深色；偏好存入 Renderer localStorage，重载后恢复。
- 侧栏可折叠至 64 px；输入区和审批面板同步调整左边界，项目/任务文本隐藏而操作图标保留。
- 所有按钮、输入框、选择器和可聚焦元素使用统一 `:focus-visible` 高对比轮廓。
- 最小窗口保持 960×640，紧凑模式下工作台、活动流和 composer 仍可见。

## 窗口恢复

SQLite migration v6 增加内部 `app_settings`。关闭窗口时保存 normal bounds、最大化和全屏状态；启动恢复前验证：

- 宽度至少 960、高度至少 640，且不超过 10000。
- 坐标/尺寸必须是有限数字。
- 与当前任意显示器 work area 至少有 100×100 px 交集。

无效、损坏或已移出显示器的状态回退到 1320×840。数据库只接受受限 setting key 与 64 KiB 以下 JSON，不向 Renderer 暴露任意设置读写 IPC。

## 自动验证

- E2E 通过平台对应快捷键打开命令面板、过滤“文件与产物”并用 Escape 关闭。
- 960×640 下折叠/展开侧栏，断言 class、按钮和活动输入区，并检查深色截图。
- 切换主题后重载 Renderer，`data-theme` 与持久偏好一致。
- Electron 关闭后重新打开 SQLite，断言窗口宽高已保存且满足最小边界。
